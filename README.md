# House Of Meda — Architecture & Commercial Design + Build Studio

**House Of Meda** is a premier luxury architectural and commercial design-build studio headquartered in India. We specialize in future-ready agile workspaces, flagship corporate headquarters, bespoke hospitality environments, and high-end retail developments.

---

## 🏛️ Studio Overview

* **Philosophy**: Minimalist luxury, biophilic corporate environments, and turnkey project execution from concept to commissioning.
* **Palette & Brand Ethos**: Warm editorial white backdrops, rich bronze (`#705335`) accents, bespoke typography (*Maison Neue* & *Fraunces*).
* **Key Offerings**:
  * Architecture & Master Planning
  * Commercial Workspace & Corporate Headquarters Fitouts
  * Luxury Hospitality & Fine Dining Spaces
  * High-End Retail & Flagship Boutiques
  * Turnkey Design + Build General Contracting

## 📂 Site Architecture

* **Home (`/` / `index.html`)**: Interactive hero showcase, dynamic expertise sliders, client rosters, and interactive footer logo trail.
* **Expertise (`/expertise`)**: In-depth breakdown of architectural design and turnkey build capabilities.
* **Projects (`/projects`)**: Filterable portfolio of corporate, retail, and hospitality projects.
* **About (`/about`)**: Studio history, founding vision, and design methodology.
* **Case Study (`/case-study`)**: Deep dives into completed landmark projects with comprehensive photography and architectural floorplans.
* **News & Press (`/news-press`)**: Architectural press releases, industry recognitions, and media features.
* **Contact (`/contact`)**: Global offices, studio inquiries, and consultation scheduling.
* **Request a Quotation**: Persistent luxury editorial modal popup for immediate corporate inquiry submission with budget and scope calculator.

## 🚀 Running the Local Server

The site includes a production-grade Python server with SPA fallback routing, asset caching, and dynamic API endpoints:

```bash
# Run server on port 8777 (or specify any port)
python server.py -p 8777
```

Navigate to: `http://127.0.0.1:8777`
