# House of Meda

Bespoke architectural interior design studio based in Bengaluru. A refined balance between form and feeling — shaping interiors that are intentional, timeless, and deeply connected to the people who inhabit them.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **3D & Animation**: Three.js / React Three Fiber / GSAP
- **Deployment**: Node.js / Vercel

## Local Development
```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)
